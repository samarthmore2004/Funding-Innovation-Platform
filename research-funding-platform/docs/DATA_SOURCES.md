# Data Sources, Provenance & Integrity

The platform separates **real, verifiable data** from **illustrative demo data** everywhere: in the database
(`record_type`, `source_name`, `source_url`, `verified_at`), in the API, in the UI (badges and banners) and in
exported reports.

### Verified funding (Grants.gov)
* Each record stores the official detail page (`https://www.grants.gov/search-results-detail/<id>`), the
  opportunity number and the retrieval timestamp (`verified_at`).
* Amounts (`awardFloor`/`awardCeiling`) and deadlines are copied as published; missing values stay empty —
  nothing is estimated.
* Eligibility codes are mapped to platform applicant types; because these are U.S. federal programmes the
  country rule is `United States`, and the eligibility text states that non-U.S. applicants are usually
  ineligible unless the notice says otherwise.
* HTML entities in official titles (e.g. `&ndash;`) are decoded on ingest. Open calls whose closing date has
  passed are stored as *closed*. **Stale forecasts** — Grants.gov still lists some forecasts whose *estimated*
  application date passed years ago — keep their official record, but the past estimate is moved into the
  eligibility text ("Forecast notice: the estimated application date … has passed") instead of being shown as an
  upcoming deadline.
* Refresh: Admin → Datasets → *Run Grants.gov sync* (or enable `GRANTSGOV_SYNC_ENABLED`). When the API is
  unreachable the sync is recorded as *failed* and the existing snapshot stays in use.

### Publications & trends (OpenAlex, Crossref)
* OpenAlex metadata is CC0. Without an API key OpenAlex grants a small shared daily budget
  (≈ $0.10/day ≈ 100 searches per IP as of October 2026), so the app never calls it at start-up; set
  `OPENALEX_API_KEY` for a personal quota.
* Live features: *Research → Live topic trend* (falls back to the local sample with an explicit note) and
  *Admin → Sync publications from OpenAlex*.
* Crossref (keyless) and OpenAlex are used for *Look up DOI* on the profile page; if both are unreachable the
  user is told to enter the publication manually.
* Publication-trend counts are keyword-query proxies (title/abstract matches), not curated field totals.

### Illustrative (synthetic) data — what it is and is not
* **Funding:** organisation names are explicitly fictional ("Example …", "Sample …", "Illustrative …",
  "Demo …"), `source_url` is empty and `source_name` reads *Illustrative sample (not a real call)*. They exist
  so that categories Grants.gov does not cover (accelerators, venture programmes, research councils outside the
  U.S., international agencies) and non-U.S. applicants can be demonstrated.
* **Patents:** numbers use the `ILLUS-<AREA>-NNNN` pattern (never a real patent number format), assignees and
  inventors are invented, citation counts are simulated; filing-volume growth curves were chosen per area to make
  trend analytics demonstrable, and prosecution status follows filing age (filings ≥ 6 years old are granted or
  abandoned, recent ones mostly pending). **Patent-derived indicators (clusters, competitors, adoption, patent strength,
  freedom-to-operate) therefore describe synthetic data** until real patents are imported.
* **Demo users, projects, own publications and history entries** are fictional and labelled "(Demo …)".

### Bringing in more real data
* **Patents:** export CSV from Google Patents (the `search URL:` preamble is detected automatically) or The Lens
  and upload it in Admin → Datasets → Patents. Imported rows get `record_type = imported`.
* **Funding:** upload CSV/JSON using the template (Admin → Datasets → Funding → *Template*). Uploaded rows are
  marked `imported` with the source "Imported by administrator (unverified)" unless the file supplies a source
  name — the platform cannot verify them automatically.
* **Live patent search:** set `PATENTSVIEW_API_KEY` (free) to enable *Patents → Live USPTO search*. This client
  follows the PatentSearch API documentation but **has not been exercised against the live service** because
  no key was available while building the project.
